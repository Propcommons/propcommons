# Reference scene sources

- `studio.hdr`: a 256 × 128 equirectangular environment generated by `tools/hdri/build.ts`. It is
  not a photograph; it is made entirely by that script and is released under CC0 1.0. Regenerate it
  with `node tools/hdri/build.ts`. It is the only environment used for previews and on the site.
- Three.js is served from the pinned `three` package in `node_modules`; nothing is fetched from the
  network at render time.
