# Asset template

`propcommons init <your-handle>/<asset-slug>` copies this folder's `asset.json` and `model.glb`
into `assets/<your-handle>/<asset-slug>/v1/` and fills in the manifest.

`model.glb` is a 10 cm placeholder box. Replace it with your own model, exported as described in
CONTRIBUTING.md, then run `propcommons validate` on the folder. This README is not copied.
