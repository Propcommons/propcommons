# propcommons (placeholder)

This npm package only reserves the name `propcommons` for the
[Prop Commons](https://propcommons.github.io/propcommons/) project, so nobody else can publish code
under it. Running it prints how to get the real tools, which run inside a clone of the repository:
see [CONTRIBUTING.md](https://github.com/Propcommons/propcommons/blob/main/CONTRIBUTING.md).
